# Responsive section menus

## Mobile section menus

On screens narrower than 768px, inline section navigation is shown as a dropdown with the current section selected. Choose an entry to open its existing page. Wider screens retain the inline section links. This applies to shared menus such as Instance Manager and Connection Manager; no configuration is required.

At desktop widths, section menus stay on one line. Extra sections appear under **More** when space is limited. More is highlighted if it contains your current page. Resize the window to reveal more section links; mobile continues to use the section dropdown.
